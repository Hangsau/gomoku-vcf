名稱（使用者 2026-11-11 定）：中文 兩儀殿（《易・繫辭》「易有太極，是生兩儀」，黑白對弈）、日文 両儀殿、韓文 음양전（양의 跟「洋醫」同音所以用陰陽）、英文 Yin-Yang Hall。入口在「挑戰」選單最下面（煉獄之門下方；沒有排行榜，放最後排行榜分頁順序才不受影響）；返回鍵回 `game.html#pick`。

## 本機跑

本機設定放 `game/duel-server/.dev.vars`（不進 git）。**`wrangler dev --var` 在這版不會生效**（2026-11-11 實測 env 拿到 null），要測閒置就在 .dev.vars 寫 `IDLE_MS=8000`、`IDLE_ASK_MS=5000` 再重開 wrangler dev；測完拿掉，不然其他測試會被閒置規則踢掉。


```bash
python -m http.server 8791 --bind 127.0.0.1                     # 在 repo 根目錄
npx wrangler@4.158.0 dev -c game/duel-server/wrangler.toml --ip 127.0.0.1 --port 8787 --var BANK_URL:http://127.0.0.1:8791
```

開 `http://127.0.0.1:8791/duel.html`。兩個玩家要用兩個不同瀏覽器（或無痕視窗），同一個瀏覽器的分頁算同一個人。

## 兩種房間

**五子棋**：普規、連珠、塔拉、塔拉山口、Swap2。黑棋自己點到禁手只提醒不判輸；非擋不可的點是禁手（抓禁）判黑輸。再來一局交換座位。

**研棋**（使用者 2026-11-11）：
- 不計時、自訂時間的五子棋房（5+5、10+10 不行），對局中可以「申請研棋」；對方同意＝這盤不計勝負、進入研棋；拒絕後 30 秒內不能再申請。
- 任何時間設定下完，結果視窗按「研棋」直接覆盤（勝負照舊）。
- 研棋中兩人共用棋盤、誰都能下、黑白輪流、不管禁手；上一手／下一手／回到實戰；退回去再下會取代後面的手順；實戰之後的手標數字。任一方按「結束研棋」回到下完狀態。
- 伺服器：`worker.js` 的 `studyMsg`、`enterStudy`，房間狀態多一個 `study`。

**閒置退出**（使用者 2026-11-11）：坐在位子上 10 分鐘沒動作就問「還在嗎？」，60 秒沒回應就離座；對局中離座＝判負（對方看到「X 太久沒回應」）。五子棋對局中只看輪到的人（從上一手算起）；等人從開始等算起；下完、研棋、VCF 競速看自己最後一個操作。伺服器用 Durable Object 的 alarm 定時檢查（建構時設的 setInterval 不會跑）。大廳卡片顯示「等了幾分」。

**VCF 明鏡台競速**（2026-11-11 使用者：從「同一題搶答」改成「各自往下做、搶 N」）：
- 兩人做同一串題目、同樣順序，倒數 3 秒後同時開始，各自往下做，先解開 3／5／10 題的贏（預設 5）。
- 開局抽 N×3 題，任何人做到剩 3 題就往後補，題目不會用完（`vcf.js` 的 `initList`、`ensureList`）。
- 下錯（對方連五、被禁手、沒四了）、時間到、按「放棄這題」＝這題失敗，停 1.2 秒直接下一題，沒有額外懲罰。不是四的手照 Rush 防呆擋下、不算錯。
- 明鏡台規則：想的時候不扣時間，第一手落下後 5 秒、每手 +1 秒（照 Rush 單人明鏡台）。每題思考上限 1／3／5 分鐘（預設 3 分鐘），到了算這題時間到。
- 題目段位初段～傳說，一律 20 手內（題庫 `game/p/段位.json` 第 3 欄 ≤ 20）。傳說段 20 手內只有 47 題，常玩會重複。
- 比賽中看不到對手下在哪，只看得到對手「第幾題・思考中／落子中」和解開幾題。
- 比賽結束：棋盤變成逐題看解法（◀ ▶ 換題；正解／我的／對手）。正解先用解開那人的手順，兩人都沒解開就用引擎算。
- 伺服器：`worker.js` 的 `vcfStart`、`vcfBegin`、`vcfMsg`、`vcfFinish`，每人各自題號、計時（`vs.p[座位]`）；結束才送 `review`（整串題目＋兩人手順）。
- 本機測試腳本（不進 git）：兩個瀏覽器打一場、四種語言×小手機不捲動檢查，做法見 2026-11-11 commit 說明。
