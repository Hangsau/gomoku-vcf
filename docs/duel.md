## 檔案

| 檔 | 做什麼 |

## 本機跑

```bash
python -m http.server 8791 --bind 127.0.0.1                     # 在 repo 根目錄
npx wrangler@4.158.0 dev -c game/duel-server/wrangler.toml --ip 127.0.0.1 --port 8787 --var BANK_URL:http://127.0.0.1:8791
```

開 `http://127.0.0.1:8791/duel.html`。兩個玩家要用兩個不同瀏覽器（或無痕視窗），同一個瀏覽器的分頁算同一個人。

## 兩種房間

**五子棋**：普規、連珠、塔拉、塔拉山口、Swap2。黑棋自己點到禁手只提醒不判輸；非擋不可的點是禁手（抓禁）判黑輸。再來一局交換座位。

**VCF 明鏡台搶答**（使用者 2026-11-11 定）：
- 兩人同一題、倒數 3 秒後同時開始，先解開得 1 分，先拿到 3 或 5 分贏。
- 明鏡台規則：想的時候不扣時間，第一手落下後 5 秒、每手 +1 秒（照 Rush 單人明鏡台；使用者 2026-11-11：對戰參考單人）；下錯（對方連五、被禁手、沒四了）或時間到＝這題出局。
- 每題思考上限 1／3／5 分鐘（預設 3 分鐘），到了沒人解開就沒人得分、顯示正解。
- 題目段位初段～傳說，一律 20 手內（題庫 `game/p/段位.json` 第 3 欄 ≤ 20）。
- 看不到對手下在哪，只看得到「思考中／落子中第幾手／出局／解開」；每題結束才公開解法。
