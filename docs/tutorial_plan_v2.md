# VCF 教學 v2：流程與順序重想（2026-11-10）

> 起因（使用者試玩回報）：① 6-3 用四四禁贏，但禁手第 7 單元才教，玩家完全不知道自己怎麼贏的；② 倒帶課問「上一手在哪」，答案不唯一（X0000 拿掉任何一顆都說得通），等於猜謎；③ 6-2、6-3 換順序結果一樣，看不出要教什麼。
> 共同根因：題目由程式挑，只驗證了「答案對不對」，沒驗證「這題有沒有用到還沒教的東西」「問題本身有沒有唯一答案」「這題能不能看出要教的那件事」。

---

## 1. 三條新的品質規則（寫進檢查程式，不過就不准上）

1. **只用教過的東西**：每個觀念（禁點、四四禁、逼禁、反四、解禁、白棋四四……）標在它被教的那一課。題目用到的觀念，必須在這課或之前教過。例：禁手課之前的黑先題，盤上不能有黑禁點，贏法不能靠禁手。
2. **每個問題都要有唯一、可推理的答案**：不問「這顆子原本在哪」這種往回猜的問題。能問的只有：往前下（正解唯一，引擎驗證）、指出某條線上的子（答案是一整組子，點哪顆都算對）、二選一判斷（引擎驗證）。
3. **示範題要真的示範到那件事**：例如反四課，錯的順序必須真的被反四而且贏不了，對的順序必須避開；換順序也一樣能贏的題不准用。

---

## 2. 新順序（9 單元 → 9 單元，但禁手大幅提前）

| 單元 | 內容 | 跟 v1 的差別 |
|---|---|---|
| 開場 | 先被打敗，再換你打（不變；題目不能有禁手相關） | 加檢查 |
| 1 認識棋盤 | 棋盤、五連、座標（完整 15×15） | 不變 |
| 2 四 | 認四（是不是四）、擋四、活四和衝四、做一個四 | 不變 |
| 3 衝四逼對方擋 | 絕對先手、擋點是確定的、亂衝會浪費 | 不變 |
| **4 黑棋的禁手** | 三種禁手、成五最優先、「這點能不能下」判斷練習 | **從第 7 單元提前**：黑棋每題都可能碰到，越早教越好 |
| 5 一兩手就贏 | 活四、四三、黑棋不能四四（白可以）、先衝一個四再做四三 | 原第 4 單元，倒帶改掉（見 §3） |
| 6 怎麼找 VCF | 找材料、找終點、往回接、擋子也是棋子、四步驟一起用 | 原第 5 單元；「往回接」改成「終點先亮出來，你往前接」 |
| 7 反四 | 擋子變成四、反四後沒有先手、換順序躲反四 | 原第 6 單元，題目重挑（規則 3），白先黑先都可 |
| 8 白棋與逼禁 | 白可以四四、逼黑擋在禁點、白先綜合 | 不變（禁手已教過） |
| 9 進階與畢業 | 解禁、長的 VCF、畢業考 | 不變 |

教學盤仍是 32 子（開場＋31 課），只是課跟子的對應跟著新順序重排；畢業考那盤（P967KE41）不變。

## 3. 「倒帶課」改成「先看終點，再往前接」

舊的問題：倒帶一手就問「這手原本下在哪」→ 答案不唯一。

新的做法（所有原本的倒帶課都改）：

1. **看結局**：盤上是贏的那一刻，手順數字全部標著。問「贏在哪一條線？」→ 點那條線上任何一顆子都算對（答案是一整組，唯一）。
2. **看因果（倒著播，但不問位置）**：按一下倒帶，退一手，**被退掉的那顆會用虛線圈留在原位、數字還在**。問的是「為什麼」，不是「在哪」：
   - 退到對方的擋子：「它為什麼非擋這裡不可？點出逼它的那條四上的子」（一整組子都算對）。
   - 退到你的子：二選一或三選一「這手做出了什麼？」（四／活四／四三，由引擎判定唯一答案）。
3. **往前下**：盤面回到開始，終點用金色虛線圈先亮出來（你知道要往哪去），自己從第一手往前下到贏。這一步才是真正的練習，正解唯一、引擎判定，走錯有說明、可退一手。

「往回接」這個思考方法，改用第 3 步教：終點先告訴你，你要自己找出怎麼接過去。這是往前推，答案唯一。

## 4. 題目來源

- **觀念示範題（反四、逼禁、解禁、四四禁）**：改用**手擺的簡單盤面**，只放跟這個觀念有關的子，乾淨、一眼看得懂；一樣全部過引擎驗證。題庫截短的題常常太雜，看不出重點（6-2 的問題就是這樣）。
- **練習題**：題庫截短題，套上 §1 三條規則篩選。
- 白先、黑先都可以用，但每題頂端標「你下黑／你下白」（已做）。
