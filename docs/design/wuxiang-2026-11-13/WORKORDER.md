# 施工單：無相界（Gomoku Rush 新挑戰模式）

**立即執行、不要只輸出計畫、不要等確認。沒改檔案就是失敗。** 進度寫本資料夾 `PROGRESS.md`（每完成一段就寫），最後寫 `REPORT.md`。

## 規則（使用者 2026-11-13 定）

1. 題目出現時黑白分明，**不計時**，想多久都可以。
2. 玩家落下第一手的那一刻，盤上**所有棋子都畫成進攻方的顏色**；之後雙方新下的子（含程式代下的防守）也是進攻方的顏色。最後一手的標記照常顯示。
3. 這一題結束（解開、答錯或按「放棄」）就**翻回真實黑白**，盤面停著讓玩家自己看。**不管對錯都不自動換題**：畫面出現「下一題」鈕，玩家按了才換；旁邊另有「結束」鈕可直接結算。（使用者 2026-11-13：「最後一手下完就變回原來的顏色…可以自己看，或是放棄也可以跳回原色，不管對錯手動進入下一題」）
4. 結算＝答對題數＋累積分數。**錯 3 題結束**（沿用其他挑戰模式的慣例；第 3 次錯也先翻回原色讓他看，按鈕變「看結果」）。對局中有「放棄」鈕：這題算錯一題、翻回原色。
5. 沒有提示、沒有悔棋。點到禁手或不是四的點，沿用現有規則（只提醒、不算錯）。
6. 有排行榜（總分高在前，同分答對題數多在前）。防作弊不處理。

## 選題

題庫 `game/p/1.json`–`10.json`，每題 `[黑子座標字串, 白子座標字串, 手數, 題目分, 進攻方 b/w, id]`。子數＝黑子數＋白子數。

子數分六階（常數 `WX_TIERS`，上限含）：`12、18、24、32、44、無上限`。

階梯：一個整數 `k`，從 0 開始。`k` 對應（子數階, 段位）依序為 (1,初段)、(2,初段)、(2,二段)、(3,二段)、(3,三段)…，也就是奇數步升子數階、偶數步升段位；子數階到六就只升段位，段位到十段為止。答對 `k+1`，答錯 `k-1`（最低 0）。

某一格沒有題或用完：同段位往下一個子數階找，再往上一階找，都沒有才降一個段位。（七段以上幾乎沒有 12 子以下的題，九、十段完全沒有。）同一局不重複出題。

## 計分

一題得分＝題庫的題目分 × 子數階加成（常數 `WX_MULT = [1, 1.2, 1.4, 1.6, 1.8, 2]`，之後試玩會調，務必集中成常數）。總分四捨五入顯示。
煉丹爐修為照其他模式：只算題目分，不含加成。
