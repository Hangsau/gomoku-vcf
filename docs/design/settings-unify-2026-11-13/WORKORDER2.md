# 施工單 2：喇叭鈕改成「音樂／音效」快速調整小框（所有畫面一致）

**立即執行、不要只輸出計畫、不要等確認。沒改檔案就是失敗。** 進度寫本資料夾 `PROGRESS2.md`，最後寫 `REPORT2.md`。

## 背景

上一張單（`WORKORDER.md`，已完成、已在本機 commit `0abc529`、**尚未部署**）把設定頁抽成共用 `game/settings.js`，並把兩儀殿的喇叭鈕、地球鈕換成齒輪。使用者看了方向後補充（2026-11-13 原話）：

> 如果要 就所有地方都可以隨時關聲音 那也沒關係 但遊戲玩家可能會要留落子聲
> 如果要這樣 就讓那個喇叭可以做到快速調整音樂跟音效 做設置 是先要離開棋局 不一定好

意思：下棋中不想為了調聲音離開棋局進設定頁；而且常見需求是「關音樂、留落子聲」，原本喇叭一按全關做不到。所以**喇叭鈕保留，功能改成點了在旁邊跳出小框，裡面兩條滑桿：音樂、音效（含落子聲）**。所有有喇叭的地方行為一致。

小框的樣子：照 `docs/design/sound-2026-11-12/project/B.dc.html`（2026-11-12 畫過的「按鈕旁小浮窗」）的排法；顏色用頁面既有色票；滑桿的樣式與行為沿用 `game/settings.js` 設定頁裡那兩條（同樣的圖示、同樣的刻度與存法）。

## 做完的樣子

- **哪裡有喇叭**：`game.html` 現有的兩顆（設定頁以外的那兩處 `[data-sound]`：約 355、459 行，先確認它們各在哪個畫面）保留；`duel.html` **大廳與房間各加回一顆**喇叭（大廳：喇叭＋齒輪；房間：喇叭＋齒輪，都在右上角，順序兩個畫面一致、跟 `game.html` 的慣例一致）。
- **點喇叭**：在按鈕下方跳出小框（靠右對齊、不超出畫面），裡面兩條滑桿「音樂」「音效」，各有圖示與目前數值的視覺回饋。拉動立刻生效、立刻存（跟設定頁同一組鍵 `vcfgame.vol.bgm`、`vcfgame.vol.sfx`，設定頁與小框互相同步）。
- **關閉小框**：點小框外任何地方、再點一次喇叭、按 Esc。小框開著時點棋盤**只關小框、不落子**（避免誤下）。
- **不離開棋局**：小框是蓋在畫面上的小浮層，不換畫面、不動 history、不影響對局、連線、計時。
- **喇叭圖示**：兩條都是 0（或總開關關著）時顯示靜音圖示，否則顯示有聲圖示。
- **總開關 `vcfgame.sound`**：喇叭不再是「一按全關」。處理方式統一成上一張單在兩儀殿用的那套（`unmuteOnVol`）：總開關是 `'0'` 的舊玩家，在小框或設定頁把任一條拉到 > 0 就打開總開關；之後沒有任何介面會再把總開關設成 `'0'`（要安靜就把兩條拉到 0）。`game.html` 也改成這樣（`game.html` 現在設定頁怎麼接 `RushSettings.init` 的 `unmuteOnVol`／`setSound`，照兩儀殿的接法統一）。「落子聲」視窗裡的「目前靜音中」提示照新邏輯仍正確。
- **只寫一份**：小框做成共用（放進 `game/settings.js` 或新檔 `game/sound-pop.js`，自帶樣式與四語文字），兩頁共用，不可各抄一份。
- 四語（zh／en／ja／ko）：音樂、音效、喇叭的 aria-label（「聲音」）。
- 觸控範圍 ≥ 44px；圖示用 inline SVG。
- 四語 × 375×667、360×640：有喇叭的每個畫面，小框開著與關著都不可捲動，小框完整在畫面內。
