# 任務：畫 Gomoku Rush 的 7 張「特色棋盤」底圖

**每畫完一張就立刻處理並存檔**；最後的檔案已經存在就跳過那一張。

## 用途
五子棋手機遊戲的棋盤底圖。程式會在圖上面自己畫 15×15 的格線、星位和棋子，所以**圖上絕對不要畫格線、方格、邊框、棋子、文字**。
整張圖是一片正上方俯視的材質，會被縮到大約 340～420 像素見方顯示。

## 每一張都要符合
- 正方形，正上方俯視，材質鋪滿整張，四個角和邊緣跟中間一樣（不要暗角、不要相框、不要留白）。
- **明暗要平均、對比要低**：格線和棋子要畫在上面，圖案太花會看不清楚。紋理是淡淡的、細的；不要有大塊的亮暗對比，不要有搶眼的物件。
- 可以在材質裡放少量很淡的小點綴（下面各張有寫），但要小、要淡、要分散，不能排成格子。
- 不要文字、不要符號、不要人物。

## 7 張（檔名固定）
1. `grass.webp` 草地：短短的草皮，鮮綠帶一點黃綠，細細的草葉紋理；零星三四朵很小的白色小花。整體中等亮度的綠。
2. `starry.webp` 星空：深藍到深紫的夜空，很淡的星雲，細小的星點均勻散開（星點要小而暗一點，不要大顆亮星）。整體很暗。
3. `beach.webp` 沙灘：細緻的淺米黃色沙子，淡淡的風紋；零星兩三個很小很淡的貝殼。整體很亮。
4. `chalk.webp` 黑板：深墨綠色的黑板，有擦過粉筆留下的淡淡霧白痕跡。整體暗。不要寫任何字或畫任何圖形。
5. `ice.webp` 冰湖：結冰的湖面，淡藍白色，幾道很細很淡的白色裂紋和小氣泡。整體很亮。
6. `denim.webp` 牛仔布：靛藍色牛仔布的斜紋織紋特寫，微微的刷白。整體中等偏暗的藍。不要縫線、不要口袋、不要鈕扣。
7. `pool.webp` 泳池：清澈的淺水泳池底，土耳其藍，水面折射在池底形成的柔和光紋（光紋要淡）。整體中等偏亮。不要畫磁磚格子、不要水道線。
