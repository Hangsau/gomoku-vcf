## 要做的（只改畫面；伺服器、擁有紀錄、領取規則都不變）

### 商店首頁
- 首頁右上的購物袋 `#openShop` 進來先到這頁：標題「商店」，一張大卡「棋具」（縮圖＋「棋子造型 N 組・棋盤花色 M 張」＋「限時免費」膠囊＋右箭頭），點了進棋具頁。N、M 是目前上架（`isShop` 且 `!isOff`）的數量；兩者都是 0 時整頁顯示「目前沒有上架的商品」、不顯示卡片。
- **「棋具」卡的縮圖用普通的棋子棋盤**（原木盤＋平面黑白子，四顆交錯；用 CSS 或 `RushSkin` 以 `classic`＋`flat` 畫，不要用商品圖）——使用者 2026-11-13：「封面照面用普通棋子棋盤就好」。
- 卡片清單由一個陣列產生，之後加別的類別只要多一筆。
- 從棋具頁（設定→棋具）的「＋」進來：直接到商店的**棋具頁**（跳過商店首頁），並停在對應的分頁（棋盤那排的＋→棋盤花色，棋子那排的＋→棋子造型）。

### 棋具頁（D）
- 頁首：返回（回商店首頁；若是從「＋」直接進來的，返回就回原本那一頁）、標題「棋具」、「限時免費」膠囊。
- 上方左邊一塊預覽棋盤，**用 `RushSkin` 真的畫**（沿用現在小框的畫法）：盤＝棋盤花色分頁目前選的那張、子＝棋子造型分頁目前選的那組。兩邊各自記住選擇，切分頁不會重設，所以可以任意混搭。
- 進頁時的初始選擇：玩家目前正在用的棋盤與棋子（不是商店商品也一樣顯示得出來——例如玩家用「夜墨」盤，預覽就是夜墨盤；但格子裡沒有它，所以沒有任何一格是選中狀態，直到玩家點一格）。
- 上方右邊：小字「棋子造型／棋盤花色」（目前分頁）、目前這件的名稱（大字）、狀態膠囊（`預設・內建`／`限時免費`／`已擁有`）、下面兩行「搭配的棋盤（或棋子）」＋另一邊目前選的名稱（是預設就加「（預設）」）。
- 兩顆分頁鈕：「棋子造型」「棋盤花色」。
- 格子 4 欄：**第一格是「預設」**（棋子＝`flat` 平面、棋盤＝`classic` 原木；內建、不用領，標「預設」；玩家正在用它時標「使用中」），後面是上架的商店商品。每格：圖＋**名稱**＋狀態字（`免費`／`已擁有`／`使用中`／`預設`）。選中的格子金框。
- 底部一顆大按鈕，只對**目前分頁選中的那一件**：沒擁有→「免費領取『名稱』」（`RushSkin.claim`）；已擁有或預設→「換上『名稱』」（`setStones`／`setBoard`）；正在用→「使用中」（不可按）。沒有任何一格選中時按鈕不顯示或不可按。
- 不再有彈出小框。
- 四語（zh／en／ja／ko）：商店、棋具、棋子造型、棋盤花色、限時免費、預設、預設・內建、免費、已擁有、使用中、搭配的棋盤、搭配的棋子、「免費領取『{n}』」、「換上『{n}』」、「棋子造型 {a} 組・棋盤花色 {b} 張」、目前沒有上架的商品、返回。商品名稱用 `RushSkin.name(it, lang)`。
- 畫面上任何地方不可出現「收費／charge／paid／有料／유료」。
- 名稱最長的是「便便與霜淇淋」與各語言的對應名稱：格子裡放不下就縮字或允許兩行，不可以被切掉、不可以超出格子。
- **四語 × 375×667、360×640：商店首頁、棋具頁兩個分頁（14 件全上架時各 8 格）都不可捲動**，底部按鈕完整在畫面內。放不下就縮預覽盤或格子高度，不要改成可捲動。
